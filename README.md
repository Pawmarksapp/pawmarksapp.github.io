# Pawmarks

Website for the Pawmarks browser extension: https://pawmarksapp.github.io

- `index.html` — landing page
- `privacy-policy.html` — privacy policy linked from the Chrome Web Store listing
- `config.json` — remote settings the extension reads once a day (set `"bulkDownloads": false` to pause bulk downloads for everyone; `"message"` is shown in the extension)

Contact: pawmarksapp@protonmail.com
