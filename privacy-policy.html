Pawmarks — Privacy Policy

Effective: 2026-10-19 · Applies to the Pawmarks browser extension (v3.4 and later)

Pawmarks is a bookmark and collection manager for image boards. It is built so that your data stays on your computer. There are no accounts, no analytics, no ads and no tracking.

What Pawmarks stores

  • Your bookmarked artists, saved posts, collections, tags and notes.
  • Your settings (look, feed interval, download filters, privacy options).
  • Cached data needed for features you use: the new-upload feed, "viewed" markers, download counters.
  • If you buy Pawmarks Plus: your licence key, its activation id and the last validation result.
  • If you use Rule34: your Rule34 API key and user id, which the extension reads from your own account's options page while you are logged in. They are stored locally and sent only to Rule34's API.

All of this lives in Chrome's extension storage on your device. The optional automatic backup writes the same data to Downloads\Pawmarks\backup.json on your computer so it survives a reinstall.

What Pawmarks sends, and to whom

  • The image boards you use (e621, Rule34): requests for post and tag data for the artists you bookmarked, using your own logged-in session, exactly as if you browsed the site. The extension identifies itself with a Pawmarks/<version> User-Agent on its own API requests and rate-limits itself.
  • A small configuration file fetched once a day from the project's own static site (GitHub Pages). It contains only feature flags and limits. No data about you is sent with that request beyond what any web request includes.
  • Lemon Squeezy (licence provider), only if you activate Pawmarks Plus: your licence key and a short instance name are sent to validate the key. See Lemon Squeezy's privacy policy.

Nothing else leaves your browser. The developer never receives your bookmarks, browsing history, or any personal data.

Permissions, explained

  • storage — keep your bookmarks and settings.
  • downloads — save posts you ask for and write the backup file (extensions can only write inside Downloads).
  • bookmarks — the optional "hidden bookmark folders" feature moves a folder's bookmarks into the extension's private storage and back.
  • history — the optional "hidden sites" feature removes visits to sites you choose from Chrome history.
  • alarms, notifications — check for new uploads on a schedule and tell you.
  • declarativeNetRequest — set the honest User-Agent on the extension's own requests. It is not used to read or alter any other traffic.
  • Host access to e621.net and rule34.xxx — add the in-page panel and read post data on those sites only.

Your control

  • Export or delete everything at any time from the extension (Export / Import / Settings).
  • Removing the extension deletes its storage. The backup file in your Downloads folder stays until you delete it.
  • Deactivating a Plus licence removes it from the browser and from the vendor's activation list.

Age

The sites Pawmarks works with host adult content. Pawmarks is intended for adults only and is listed as mature content in the Chrome Web Store.
